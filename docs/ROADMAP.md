# Дорожная карта платформы

Список из 178 возможностей LMS составлен по обзору рынка (Moodle, Canvas, iSpring, GetCourse, Stepik, Docebo, Duolingo и др.).
Пользователь идёт по нему блоками и про каждый пункт говорит: «делай», «отложим» или «не нужно».
**Номера пунктов постоянные** — пользователь ссылается на них.

Обозначения: ✅ сделано · ⏸ отложено · ❌ не нужно / пока нет · ❓ ждёт решения · ⏭ ещё не обсуждали · 🟡 было частично до списка

Последнее обновление: 13.10.2026 (после PR про роли и кабинет родителя).

- ✅ **Кабинет родителя**: роль «Родитель», прогресс ребёнка простыми словами («Что уже умеет», «Сейчас изучает»),
  посещаемость, успехи, связь с преподавателем. Тексты «для родителей» — у курса и разделов в редакторе курса. (PR #6)
- ✅ Кнопка «Как видит родитель» в профиле ученика (предпросмотр для персонала).
- ✅ **Простое создание курса**: одна форма (название + потоки + план курса списком → разделы и уроки создаются сразу),
  карточка «Готовность курса» (уроки без текста, потоки, кнопка «Опубликовать»), редкие настройки свёрнуты,
  новый урок сразу открывается с шагом «Текст», кнопки «К курсу» / «Следующий урок», предупреждение о несохранённом шаге. (PR #7)
- ✅ **Визуальный редактор текста** (как на Stepik): уроки, вопросы, задания, база знаний. Кнопки с подписями,
  выноски, таблицы, картинки, видео, формулы; вставка с сайтов с сохранением оформления; режим «Разметка» для опытных.
  Хранится по-прежнему Markdown. (PR #8)
