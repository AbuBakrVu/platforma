# Platforma

Платформа обучения: курсы с разделами и уроками, лабораторные с терминалом в браузере, пробные экзамены, расписание, XP и рейтинг, сертификаты с QR.

## Дизайн

Выбранное направление — **A · Как в CRM** (стиль crm.bakr.pro): серо-зелёный фон, белые карточки, зелёный акцент `#1E5A3C`, шрифт Onest.

Макеты в [`designs/`](designs/):

- `index.html` — переключатель между направлениями A–D
- `a-crm.html` — главный экран студента
- `a-course.html` — страница курса и урока
- `a-lab.html` — лабораторная: задания + терминал
- `a-exam.html` — пробный экзамен
- `a-rating.html` — рейтинг потока
- `a-certificate.html` — сертификаты с QR-проверкой
- `a.css`, `icons.svg` — общие стили и иконки направления A

Посмотреть локально:

```bash
python3 -m http.server 4173 --directory designs
```
