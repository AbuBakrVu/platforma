# Platforma

Платформа обучения: курсы с разделами и уроками, лабораторные с терминалом в браузере, пробные экзамены, расписание, XP и рейтинг, сертификаты с QR.

```
web/        приложение: Next.js 16 + TypeScript + Drizzle ORM + PostgreSQL
labs/       сервис лабораторий: контейнеры студентов и терминал по WebSocket (необязательный)
designs/    HTML-макеты (направление A — «Как в CRM» — выбрано)
docker-compose.yml   запуск на сервере
```

## Что уже работает

**Студент**
- Вход и регистрация **только по коду приглашения** (ссылка вида `/login?code=XXXX-XXXX` открывает регистрацию с кодом)
- Обзор: текущий урок, прогресс, место в рейтинге, посещаемость, события недели
- Навыки → курс → урок: разделы, закрытые до даты разделы, отметка «пройдено» с начислением XP (один раз)
- Урок состоит из **шагов**: текст, видео, документ, вопрос, карточки, SCORM/xAPI. Показ по одному шагу (полоска шагов как на Stepik) или **лонгридом** — всё на одной странице с вопросами по ходу текста. Урок не засчитывается, пока не пройдены обязательные шаги
- **Видеоплеер**: скорость 0,5–2× (запоминается), выбор качества, субтитры (.vtt/.srt), главы с переходом и отметками на полосе, продолжение с места остановки, горячие клавиши; шаг засчитывается после просмотра 90%
- **Защита видео**: файлы отдаются только вошедшим студентам с доступом к курсу, без кнопки «Скачать» и контекстного меню, плавающий водяной знак с именем, почтой и датой
- **Документы**: PDF и картинки открываются прямо на странице; Word/PowerPoint/Excel — тоже, если включён конвертер (профиль `office`), иначе скачиванием
- **Вопросы внутри урока**: один ответ, несколько ответов, ввод ответа; проверка на сервере, объяснение после верного ответа
- **Карточки с интервальным повторением** (SM-2, как в Anki): «Не помню / Трудно / Помню / Легко», раздел «Повторение» со счётчиком в меню
- **Лаборатории**: своя учебная машина с терминалом в браузере (несколько вкладок), задания с автопроверкой скриптом, подсказки, таймер, «Сбросить среду»; выполненные задания сохраняются при сбросе. Раздел «Лаборатории» со списком всех лабораторных
- **Материалы для скачивания** к курсу и к урокам, «Скачать всё» одним архивом
- **SCORM 1.2, SCORM 2004, xAPI (Tin Can), cmi5**: импорт zip из iSpring, Articulate, Captivate и т.п.; встроенное LRS сохраняет прогресс, баллы и статус, завершение засчитывает шаг
- Расписание потока на 4 недели, ссылка на онлайн-занятие
- Пробные экзамены: таймер, навигация по вопросам, «отложить», автосохранение ответов, вопросы «один ответ», «несколько ответов», «расставить по порядку»; результат с разбором ошибок и XP за первую сдачу
- Рейтинг потока за неделю / месяц / всё время

**Рабочее меню сотрудника** (своё меню вместо ученического; администратор видит всё, остальные — разделы по своим правам)
- Потоки и привязка курсов к ним
- Люди и приглашения: коды с ограничением числа использований и сроком, смена роли/потока, новый пароль, удаление
- Курсы: разделы с датой открытия, уроки; порядок **перетаскиванием** (урок можно перенести в другой раздел) или стрелками
- **Экзамены**: перемешивание вопросов и вариантов, баллы за вопрос, объяснения, режим разбора (полный / только ошибки / только балл)
- **Домашние задания** с проверкой по рубрике: текст и файлы, «принято» или «на доработку» с комментарием, очередь «Проверка заданий»
- **Журнал оценок** потока по курсу с выгрузкой в Excel
- **Геймификация**: уровни и звания, достижения (в том числе секретные и сезонные), серия дней с заморозками, дневная цель,
  задания дня и челленджи, монеты и магазин наград, лиги недели, командный зачёт, дуэли 1×1, конфетти, аватары и рамки
- **Кабинет родителя**: прогресс ребёнка простыми словами — «Что уже умеет» и «Сейчас изучает» по текстам «для родителей»
  у курса и разделов, посещаемость, успехи, отзывы преподавателя, связь с преподавателем. Родитель приходит по приглашению из профиля ученика
- **Роли и права**: персонал с ролями (куратор, методист, руководитель, наблюдатель или свои) — каждая видит только свои разделы меню;
  внешние ученики (клиенты, партнёры) — только выданные курсы, без внутренних разделов; профиль пользователя со всей учёбой,
  связями и журналом действий; «Войти как» для поддержки (с записью в журнал)
- **Общение**: обсуждение под каждым уроком (ответы, упоминания @Имя, реакции); форум с разделами по курсам и вопросами-ответами
  (голосование, «лучший ответ» +15 XP); личные сообщения с преподавателями и наставником и общий чат потока; объявления для потока или всех
  (закреплённые — на «Обзоре»); наставники и страница «Подопечные»; база знаний со статьями-разделами и поиском.
  Текст пользователей показывается безопасно: HTML и опасные ссылки не пропускаются
- **Программы обучения**: цепочка курсов («DevOps-инженер с нуля»: Docker → Kubernetes), назначается потоку целиком; по порядку — следующий курс открывается, когда пройден предыдущий
- **Последовательное прохождение** курса: следующий урок открывается, только когда пройден предыдущий
- **Черновики и отложенная публикация** курсов и уроков: «Опубликовать с …» — студенты увидят курс или урок в указанное время
- **История версий** каждого шага с возвратом к любой версии и **журнал изменений курса** (кто, что, когда)
- **Библиотека**: шаг сохраняется в библиотеку и вставляется в другие уроки и курсы — связанно (правка сразу везде) или копией; копирование урока целиком в другой курс
- **Экспорт и импорт курса** одним архивом (шаги, видео, документы, SCORM, материалы) — перенос между установками платформы
- **Лабораторные**: шаблоны сред (Linux, Ubuntu, Python, Kubernetes k3s, Docker), скрипт подготовки, задания со скриптами проверки
- Конструктор урока: шаги перетаскиваются, у каждого типа свой редактор. Текст — Markdown с панелью: заголовки, код, таблицы, списки задач, формулы KaTeX (`$…$`, `$$…$$`), выноски, видео YouTube/Rutube/VK по ссылке (`@[video](ссылка)`), картинки (кнопкой, перетаскиванием или вставкой из буфера), живой предпросмотр
- Расписание: лекции, практики, дедлайны; отметка посещаемости
- Экзамены: вопросы в простом формате (вариант на строку, правильный — со `*`), публикация, последние результаты
- Удаление демо-данных одной кнопкой (или `docker compose run --rm migrate npm run db:remove-demo`) — ваши курсы и люди не затрагиваются

Заглушки: сертификаты.

Ограничения: водяной знак не мешает записать экран, а делает запись адресной — по ней видно, чей аккаунт. SCORM/xAPI-контент выполняется на домене платформы, поэтому загружать пакеты может только персонал. Видео с YouTube/Rutube/VK встраивается их плеером — водяного знака и учёта просмотра там нет.

## Установка на сервер

Нужен Linux-сервер с доступом в интернет и домен, A-запись которого указывает на сервер.

```bash
git clone https://github.com/AbuBakrVu/platforma.git && cd platforma && sudo ./install.sh
```

Установщик спросит **домен**, **логин (email)** и **пароль администратора**, затем сам:

- поставит Docker, если его нет (с вашего согласия);
- сгенерирует пароль базы и найдёт свободный порт (с 3100), запишет `.env` с доступом только для root;
- соберёт и запустит контейнеры, создаст администратора;
- настроит HTTPS: если на сервере работает nginx — добавит сайт в `/etc/nginx/conf.d/` и выпустит сертификат через certbot;
  если работает Caddy — допишет блок сайта в его Caddyfile (с резервной копией; сертификат Caddy выпустит сам);
  если порты 80/443 свободны — включит встроенный Caddy; если их занимает другой прокси (traefik и т.п.) — подскажет, куда проксировать.

Сервис уживается с другими проектами на сервере: своё имя `platforma` и сеть, база наружу не открыта, приложение слушает только `127.0.0.1`.

**Обновление:** `git pull && docker compose up -d --build` — миграции применятся автоматически.
**Сменить пароль администратора:** `sudo ./install.sh` ещё раз (пароль базы и порт сохранятся).
**Резервная копия базы:** `docker compose exec db pg_dump -U platforma platforma > backup.sql`
**Резервная копия файлов** (видео, документы, SCORM): том `platforma_uploads` — `docker run --rm -v platforma_uploads:/d -v "$PWD":/b alpine tar czf /b/uploads.tgz -C /d .`

**Большие файлы.** Видео загружаются потоком, без ограничения в 1 МБ, лимит — `MAX_UPLOAD_MB` (по умолчанию 4 ГБ). Установщик сам прописывает его в nginx;
если прокси настраиваете вы — поднимите `client_max_body_size` (nginx) или аналог. Видео лучше загружать в mp4 (H.264): перекодирования на сервере нет,
разные качества загружаются отдельными файлами.

**Word/PowerPoint в браузере.** Профиль `office` (установщик спросит) поднимает Gotenberg — LibreOffice в отдельном контейнере.
При загрузке документ конвертируется в PDF, студент видит его прямо на странице. Без профиля такие файлы доступны только скачиванием.

### Вручную, без установщика

```bash
cp .env.example .env   # домен, POSTGRES_PASSWORD (openssl rand -hex 24), порт
docker compose up -d --build
echo -n 'пароль' | docker compose run --rm -T migrate npm run -s db:admin -- admin@example.kz "Имя"
```

Проверка: `curl http://127.0.0.1:3100/api/health` → `{"ok":true}`.

## Лаборатории

Сервис `labs/` поднимает для каждого студента контейнер из указанного в уроке образа, выполняет скрипт подготовки,
отдаёт терминал по WebSocket (путь `/lab-ws/`) и запускает скрипты проверки заданий. Ограничения на среду:
память и CPU из настроек урока, до 1024 процессов, время жизни (потом среда удаляется сама), по умолчанию без сети,
`no-new-privileges`. Одновременно — не больше `LAB_MAX_SESSIONS` сред (по умолчанию 20).

Включение: `sudo ./install.sh` → «Включить лаборатории» (добавит профиль `labs`, `LAB_SECRET`, путь `/lab-ws/` в nginx/Caddy).

**Безопасность — прочитайте до включения.**
- Сервису нужен `/var/run/docker.sock`, а это равносильно root-доступу к серверу. Сам сервис наружу не открыт и принимает
  команды только от приложения (общий секрет), терминал — только по подписанному токену на 2 минуты.
- Обычные среды отделены от сервера как обычные контейнеры. **Привилегированные** (нужны для Kubernetes/k3s и Docker внутри)
  отделены слабо: студент в них root и при желании выберется на хост.
- Среды с доступом в интернет видят и порты самого сервера.
- Поэтому, если на сервере работают CRM с данными клиентов, разместите лаборатории **на отдельной машине**:
  скопируйте туда каталог `labs/`, запустите `docker build -t platforma-labs labs && docker run -d --restart unless-stopped
  -v /var/run/docker.sock:/var/run/docker.sock -e LAB_SECRET=… -p 127.0.0.1:3200:3200 platforma-labs`, на основном сервере
  в `.env` укажите `LAB_RUNNER_URL=http://<адрес машины>:3200` и `LAB_SECRET`, а в прокси — `/lab-ws/` на ту машину
  (соединение между машинами закройте firewall'ом или VPN).

Образы скачиваются при первом запуске среды — первый старт может занять пару минут.

## Локальная разработка

Нужен PostgreSQL 16 и Node 22+.

```bash
cd web
cp .env.example .env.local
createdb platforma
npm install
npm run db:migrate && npm run db:seed
npm run dev
```

Демо-вход: `demo@platforma.local`, пароль — `SEED_DEMO_PASSWORD` из `.env.local`. Пересоздать данные: `npm run db:seed -- --reset`.
Загруженные файлы лежат в `web/data/uploads` (в git не попадают).
Лаборатории локально без Docker: `cd labs && npm install && LAB_SECRET=<как в web/.env.local> LAB_DRIVER=local PORT=3210 node runner.mjs`
и в `web/.env.local` — `LAB_RUNNER_URL=http://localhost:3210`, `LAB_SECRET`, `LAB_WS_URL=ws://localhost:3210`.
Режим `local` запускает оболочку прямо на вашей машине во временном каталоге — только для разработки, в production он запрещён.
После изменения `src/db/schema.ts`: `npm run db:generate` и закоммитьте новую миграцию из `web/drizzle/`.
